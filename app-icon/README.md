# Ideate app icon

A light bulb whose glass is a brain made of five overlapping circles in IntelliJ colours, with three
square bars as the base. Chosen on 24 Nov 2026 as option "C4 · Bulb, IntelliJ colours".

There are two sets with the same layout: `dark/` (black tile, circles brighten where they overlap) and
`light/` (white tile, circles darken where they overlap).

| Platform | Files | Shape |
|---|---|---|
| macOS | `macos/Ideate.icns`, `macos/Ideate.iconset/`, `macos/ideate-macos.svg` | 824 px rounded square centred on a 1024 px transparent canvas, no drop shadow |
| Windows | `windows/ideate.ico` (16, 20, 24, 32, 40, 48, 64, 128, 256 px), `windows/png/` | rounded square, full size |
| Linux | `linux/hicolor/<size>x<size>/apps/ideate.png`, `linux/hicolor/scalable/apps/ideate.svg` | rounded square, full size |
| Android | `android/res/` (adaptive icon XML, foreground and monochrome layers, legacy icons, background colour), `android/play-store-512.png` | bulb kept inside the middle 66 dp circle of the 108 dp layer |
| iOS | `ios/AppIcon-1024.png` | full square, no transparency |

`ideate-square.svg`, `ideate-rounded.svg` and `ideate-circle.svg` at the top of each set are the masters.

Nothing here is used by the desktop or Android build yet.

## Rebuilding

Every file is generated by `make_icons.py`; change the colours or shapes there, not in the outputs.
It needs `rsvg-convert` (`brew install librsvg`) and, for the `.icns`, macOS `iconutil`.

```
python3 app-icon/make_icons.py app-icon
```
